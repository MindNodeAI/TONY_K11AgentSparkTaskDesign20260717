                 AgentSpark 平台使用說明書
            
      
            
      了解 AI Agent 運作架構，掌握編寫高價值任務的訣竅。
      
        
      
        
        
      
            
            
      
                
       1. 什麼是 AI Agent (智慧代理)？
      
                
      
                    
      傳統的 ChatGPT 只是「提示詞與回答 (Prompt & Response)」；而 **AI Agent 是一套能「理解任務、取得資料、採取行動、檢查結果」的工作系統**。
      
                    
      您可以把一個完整的 AI Agent 理解成以下的公式：
      
                    
      
                        AI Agent ＝ 角色大腦 ＋ 能力模組 ＋ 任務指令 ＋ 參考知識 ＋ 工具 ＋ 工作流程 ＋ 記憶 ＋ 治理規則 ＋ 輸出標準
                    
      
                    
      用硬體製造來比喻：
      Skill (能力模組) 是「組件」；Task (本次任務) 是「工單」；Workflow 是「製程」；Guardrail 是「品管標準」；而 Agent 就是能整合這一切完成交付的「智慧工廠」。
      
                
      
            
      

            
            
      
                
       2. Agent 核心組件拆解
      
                
      
                    
      
                        
                            
      
                                核心組件
                                回答的問題
                                具體內容
                            
      
                              
                        
                            
      
                                Identity / Role
                                我是誰？
                                Agent 名稱、角色、專長、服務對象、最終目標
                            
      
                            
      
                                Skill
                                我會做什麼？
                                可重複使用的專業能力、方法、標準 SOP (如：市場診斷、文案撰寫)
                            
      
                            
      
                                Task
                                這一次要完成什麼？
                                本次具體任務、限制、交付內容 (如：為某客戶寫 3 篇貼文)
                            
      
                            
      
                                Reference
                                我依據什麼？
                                法規、品牌規範、研究資料、歷史範例
                            
      
                            
      
                                Workflow
                                我依什麼順序做？
                                執行步驟、條件分支、錯誤處理流程
                            
      
                            
      
                                Guardrails
                                哪些事情絕對不能做？
                                禁止事項、安全邊界、事實查核
                            
      
                            
      
                                Human Approval
                                何時必須停下來？
                                遇到發布、寄信、刪除等高風險操作時的「人工審核點」
                            
      
                              
                    
      
                
      
            
      

            
            
      
                
       3. 如何寫出好的「工作痛點與任務」？
      
                
      要在本平台建立有效的藍圖，請提供「具體場景」而非空泛的指令。
      
                
      
                    
      
                        
       錯誤示範 (太過空泛)
      
                        
        
                            
      • 幫我寫行銷文案
        • 
                            
      • 做財務報表分析
        • 
                            
      • 幫我回覆客戶信件
        • 
                        
      
                        
      ❌ 結果：AI 只會給出一般般的提示詞，無法形成具備審核點與防錯機制的有效工作流。
      
                    
      
                    
      
                        
       正確示範 (具體場景)
      
                        
        
                            
      • 根據客戶過往的投訴紀錄，撰寫帶有安撫情緒的退款信件，並提醒法務風險。
        • 
                            
      • 每週統整跨部門專案進度，自動標註延遲的任務，並生成檢討會議的大綱。
        • 
                        
      
                        
      ✅ 結果：系統能精準設計出包含「資料分析、風險標註、審核點、格式輸出」的專業 Agent。
      
                    
      
                
      
            
      
            
            
            
      
                
       4. 平台操作三步驟
      
                
      
                    
      
                        
      1
      
                        
      
                            
      建立藍圖 (Create)
      
                            
      在「建立任務」頁籤中輸入您的角色與痛點，或是讓系統為您推薦高價值的任務。點擊生成後，AI 會自動為您建構包含 Onboarding UX 與 Workflow 的初始 Canonical Task。
      
                        
      
                    
      
                    
      
                        
      2
      
                        
      
                            
      編譯與測試 (Compile & Test)
      
                            
      在左側編輯器微調任務邏輯、設定安全審核點。接著，切換到右側的「模擬測試」頁籤，直接與您設計的 Agent 對話，驗證工作流是否順暢、迎賓語是否親切。
      
                        
      
                    
      
                    
      
                        
      3
      
                        
      
                            
      打包下載 (Export)
      
                            
      確認無誤後，點擊「封裝下載」。系統會將您的設定轉譯為 ChatGPT 和 Gemini 看得懂的標準 Markdown 格式，打包成以「任務名稱」命名的 ZIP 檔供您佈署。
